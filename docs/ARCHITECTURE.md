# M1 Player Portal — architecture v1.2

- Obsidian vault: private GitHub repository `m1-universe`.
- Site: Astro, deployed to GitHub Pages from this PUBLIC repository.
- Player changes: GitHub Issues, reviewed by Warden; no automatic canon edits.

- Future: interactive star maps, timelines, character dossiers, and ChatGPT integration.
